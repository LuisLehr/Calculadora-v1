# Calculadora - pt-BR.
Esse software foi desenvolvido em Java com o objetivo de reunir diferentes operações matemáticas e conversões em um único programa executado pelo terminal.

O usuário pode acessar todas as funcionalidades por meio de um menu interativo.

## ✅ Principais funcionalidades
O software possui cinco opções principais:

* **Calculadora simples** - Realiza adição, subtração, multiplicação, divisão, potenciação e raiz quadrada.
* **Calculadora de IMC** - Calcula o Índice de Massa Corporal e apresenta a classificação correspondente.
* **Conversor de bits e bytes** - Converte valores entre `BIT`, `B`, `KB`, `MB`, `GB`, `TB` e `PB`.
* **Conversor de medidas** - Converte valores entre `MM`, `CM`, `DM`, `M`, `DAM`, `HM` e `KM`.
* **Conversor de massas** - Converte valores entre `MG`, `CG`, `DG`, `G`, `DAG`, `HG` e `KG`.

## 🚀 Começando
Essas instruções permitirão que você obtenha uma cópia do projeto em operação na sua máquina local para fins de desenvolvimento e teste.

## 📝 Como executar o software
Para executar o sistema, instale o Java Development Kit (JDK) 21 e abra o terminal na pasta principal do projeto.

Compile o projeto usando o Maven:

```bash
mvn compile
```

Em seguida, execute a classe principal:

```bash
java -cp target/classes Principal
```

Também é possível executar a classe `Principal.java` diretamente por meio da sua IDE.

# Calculator - en-US.
This software was developed in Java to provide different mathematical operations and conversions in a single terminal application.

Users can access all features through an interactive menu.

## ✅ Main Features
The software provides five main options:

* **Simple calculator** - Performs addition, subtraction, multiplication, division, exponentiation, and square root calculations.
* **BMI calculator** - Calculates the Body Mass Index and displays the corresponding classification.
* **Bits and bytes converter** - Converts values between `BIT`, `B`, `KB`, `MB`, `GB`, `TB`, and `PB`.
* **Length converter** - Converts values between `MM`, `CM`, `DM`, `M`, `DAM`, `HM`, and `KM`.
* **Mass converter** - Converts values between `MG`, `CG`, `DG`, `G`, `DAG`, `HG`, and `KG`.
